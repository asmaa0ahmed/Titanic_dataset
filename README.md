# Titanic ML GridSearch Project

## Description
This project predicts **Titanic survivors** using multiple machine learning models with **GridSearchCV** to find the best hyperparameters.  
Models used:
- Random Forest
- SVM
- KNN

## Dataset
The dataset is from Kaggle: [Titanic – Machine Learning from Disaster](https://www.kaggle.com/c/titanic)

## Project Steps
1. Load the dataset
2. Handle missing values
3. Encode categorical variables
4. Split data into train and test sets
5. Apply GridSearchCV to different models
6. Evaluate model performance

## Requirements
- Python 3.x
- pandas, scikit-learn

## How to Use
1. Open the notebook in Colab or Jupyter
2. Run all the cells in order
3. Check the best hyperparameters and model performance
